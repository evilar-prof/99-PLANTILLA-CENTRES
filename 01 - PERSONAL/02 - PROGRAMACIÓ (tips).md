# 0. Programacions per Trimestre

> Determinar quines RAs es faràn i en quin trimestre.
> 
> Exemple:
> - Si hi ha 8 RAs i 3 trimestres: 8/3 = 2.5 temes per trimestre
> 	- 1r trimestre -> 3
> 	- 2n trimestre -> 2
> 	- 3r trimestre -> 3

# 1. Taula programacions

> Crear una taula la qual tingui tots els temes/RAs del curs i després, volcar els RAs/Temes per cada trimestre.

| Trimestre | Tema   | Subtema | RA       | Criteris d'avaluació                         | Notes |

| 1r        | Tema 1 |         | RA1      | 1. Criteri 1<br>2. Criteri 2<br>3. Criteri 3 |       |
| 1r        | Tema 2 |         | RA2      | 1. Criteri 1<br>2. Criteri 2<br>3. Criteri 3 |       |
| 2n        | Tema 3 |         | RA3, RA4 | 1. Criteri 1<br>2. Criteri 2<br>3. Criteri 3 |       |

> També podem fer que una pràctica englobe diferents Temes/RAs.
> - Per exemple, en el mòdul "0373 - Llenguatge de Marques", per practicar la RA4 (XML-DOM), podem fer una pràctica que englobe:
> 	1. HTML, CSS (RA2)
> 	2. XML (RA3)
> 	3. XML-DOM (RA4)
> - En aquest cas, quadra perquè crea un treball més realista i recorden anteriors RAs, i així entrem en un àmbit de treball acumulatiu/globalitzat.
